# 🤖 AGENTS.md — Правила та Стандарти Розробки для ШІ-Агентів

Цей документ містить обов'язкові правила для всіх ШІ-агентів (Gemini, Claude, Cursor, Copilot тощо), які працюють у репозиторії **3D Club Studio («3D Кузня Чудес»)**.

---

## 📌 1. Золоті Правила Репозиторію

### 1.1. Обов'язковий Git Commit & Push після завершення задач
- **НІКОЛИ** не залишати виконану задачу без git-коміту та пушу у віддалений репозиторій (`origin/main`).
- Кожне завершене виправлення, рефакторинг чи нова функція повинні супроводжуватися:
  1. Перевіркою `git status` та відсутності сміттєвих тимчасових файлів.
  2. Синхронізацією версії проєкту за потреби (див. §1.2).
  3. Зрозумілим змістовним повідомленням коміту (за конвенцією Conventional Commits: `feat:`, `fix:`, `refactor:`, `style:`, `docs:`).
  4. Командою `git push origin main`.

### 1.2. Синхронізація Версії Проєкту
Якщо випускається нова версія, номер версії **ОБОВ'ЯЗКОВО** має бути оновлений у ВСІХ таких місцях одночасно:

| Файл | Де саме | Ідентифікатор |
|---|---|---|
| `index.html` | Бейдж у хедері | `id="app-version-pill"` (клас `.version-pill`) |
| `index.html` | Нижній кутовий індикатор | `id="app-version-corner"` (клас `.version-corner-badge`) |
| `src/app.js` | Поле `version` у `serializeState()` | `version: 'X.Y.Z'` |
| `src/passportPrintController.js` | Підвал паспорта деталі у методі `renderRetinaCanvas()` | `«3D Кузня Чудес vX.Y.Z»` |
| `README.md` | Заголовок репозиторію та заголовки розділів | `v1.X.Y … Edition` |

## 🌐 2. Архітектурні Контракти

### 2.1. 100% Offline-First та Нульові Залежності
- Студія розрахована на шкільні комп'ютерні класи, де інтернет може бути повільним, заблокованим або відсутнім.
- **ЖОДНИХ зовнішніх CDN-посилань, зовнішніх шрифтів (Google Fonts тощо) чи аналітики.**
- **ЖОДНИХ збирачів, npm/node залежностей у рантаймі.** Чистий Vanilla JavaScript (ES6+), нативний CSS3 та Three.js r128 (`lib/three.min.js`), що завантажуються локально.
- **ЖОДНОГО TypeScript, ESLint, Prettier чи іншого тулінгу.** Лише ручний контроль якості.

### 2.2. Адаптивність та Контракт Екранів (Шкільні Ноутбуки)
- Основний робочий пристрій учня/викладача — це шкільний ноутбук із роздільною здатністю **1366×768** або планшет **1024×768**.
- **Верхня панель (Topbar)**: кнопки дій (`💾 STL`, `📸 V1`, `📋 Паспорт` тощо) **НІКОЛИ** не повинні обрізатися або виходити за межі екрана. При зменшенні ширини використовується медіа-адаптація:
  - `< 1550px`: ховається довгий підзаголовок `.brand-subtitle`.
  - `< 1366px`: компактні відступи та розміри кнопок, горизонтальний скрол без обрізання.
  - `< 1120px` / `< 768px`: компактне групування та ховання необов'язкових текстових підписів.
- **Всі модальні вікна** повинні мати `max-height: 90vh`, `overflow-y: auto` і кнопку швидкого закриття `✕`.

## 🏗️ 3. Архітектура Модулів та Порядок Завантаження

### 3.1. Модульна Структура (IIFE → `window.*`)
Кожен `.js` файл — це **IIFE** (Immediately Invoked Function Expression), яке реєструє свій клас або інстанс на `window`. Це і є «модульна система» проєкту — **не чіпати цю конвенцію**.

| Файл | `window.*` | Тип | Призначення |
|---|---|---|---|
| `lib/three.min.js` | `window.THREE` | Бібліотека | 3D-рушій Three.js r128 |
| `src/voxelFont.js` | `window.VoxelFont` | Клас | Воксельний 5×7 шрифт (UKR + LAT + іконки) |
| `src/soundEffects.js` | `window.StudioSound` | **Інстанс** | Процедурний аудіо-синтезатор |
| `src/safeStorage.js` | `window.SafeStorage` | Об'єкт | Безпечна обгортка `localStorage` |
| `src/historyManager.js` | `window.HistoryManager` | Клас | Undo/Redo (до 35 кроків) |
| `src/missionManager.js` | `window.MissionManager` | Клас | Базові 12 місій та розширюваний каталог |
| `src/content/adventurePack.js` | `window.StudioAdventurePack` | Об'єкт | 12 додаткових місій і компактних рельєфів |
| `src/adventureShelf.js` | `window.AdventureShelf` | Клас | Тематична полиця та автоматичні лічильники каталогу |
| `src/pixelEditorTools.js` | `window.PixelEditorTools` | Клас | Віддзеркалення, поворот і зміна висот із Undo |
| `src/lessonCompanion.js` | `window.LessonCompanion` | Клас | План години, таймер і творчі виклики |
| `src/snapshotCompareController.js` | `window.SnapshotCompareController` | Клас | Порівняння V1 ↔ V2 знімків |
| `src/passportPrintController.js` | `window.PassportPrintController` | Клас | Генератор паспорта деталі (Canvas → PNG) |
| `src/generators/minecraftForge.js` | `window.MinecraftForgeGenerator` | Клас | ⛏️ Майнкрафт-Кузня |
| `src/generators/dualIllusion.js` | `window.DualIllusionGenerator` | Клас | 🔮 Оптичний Перевертень |
| `src/generators/physicsMechanics.js` | `window.PhysicsMechanicsGenerator` | Клас | 🎯 Фізика без Шестерень |
| `src/generators/mobMutator.js` | `window.MobMutatorGenerator` | Клас | 👾 Мутатор Мобів |
| `src/sceneManager.js` | `window.SceneManager` | Клас | 3D-сцена, камера, STL-експорт |
| `src/app.js` | *(немає — самозапуск)* | IIFE | Головний контролер UI |

### 3.2. Порядок `<script>` тегів — КРИТИЧНИЙ
Порядок у `index.html` **визначає залежності**. `app.js` завантажується **останнім**, бо він є кореневим контролером і створює інстанси всіх інших модулів.
```
three.min.js → voxelFont → soundEffects → safeStorage → historyManager →
missionManager → snapshotCompareController → passportPrintController →
generators/* → content/adventurePack → adventureShelf → pixelEditorTools →
lessonCompanion → sceneManager → app.js
```
**Ніколи** не змінювати цей порядок без перевірки всіх `window.*` залежностей.

Опис контрактів розширень і меж перевірки: `docs/EXTENSIONS.md`.

### 3.3. Контракт Генераторів
Усі 4 генератори дотримуються спільного інтерфейсу:
- `build3D(params)` → повертає `THREE.Group` для `sceneManager.setModel()`
- `getState()` → серіалізований об'єкт для автозбереження
- `setState(data)` → відновлення стану з автозбереження
- Пресети визначаються у масиві `this.presets[]` або об'єкті `PRESETS {}`

## 🔗 4. Data-Attribute Конвенції (HTML ↔ JS зв'язки)

Замість жорстких DOM-ідентифікаторів для повторюваних елементів, UI використовує `data-*` атрибути. При додаванні нових елементів **обов'язково** використовувати ці конвенції:

| Атрибут | Призначення | Приклади значень |
|---|---|---|
| `data-tab` | Перемикач 4 генераторів | `minecraft`, `illusion`, `physics`, `mob` |
| `data-mc-preset` | Пресет Майнкрафт-Кузні | `sword`, `pickaxe`, `creeper`, `tnt`, `shield`, `slot_calibrator`… |
| `data-mc-brush` | Рівень пензля (0 = гумка) | `0`–`4` |
| `data-il-preset` | Пресет Оптичного Перевертня | `short`, `cipher`, `1`, `2` |
| `data-camera-view` | Ракурс камери (3D-вʼюпорт) | `iso`, `front`, `top`, `side90` |
| `data-view-mode` | Режим відображення | `editor`, `split`, `viewport` |
| `data-insert-sym` | Вставка 3D-символу у текстове поле | `★`, `⚔`, `⛏`, `💀`, `👑`, `♥` |
| `data-mission-check` | Чекліст поточної місії | `size`, `connected`, `mono` |
| `data-mission-filter` | Фільтр каталогу місій | `all`, `relief`, `optical`, `cardboard`… |

> **Застарілий атрибут:** `data-cam-view` — дублікат `data-camera-view`; у новому коді використовувати лише `data-camera-view`.

## 🔊 6. Аудіо-Двигунець (Web Audio API)

- Процедурний синтезатор у `src/soundEffects.js` працює через нативний `AudioContext`.
- Глобальний інстанс: `window.StudioSound` (не клас — **готовий об'єкт**).
- Рівень гучності (`masterGain`) має бути достатнім (орієнтир `0.70`), щоб звуки чітко чути на тихих динаміках старих ноутбуків.
- Всі виклики аудіо повинні бути безпечними (`try/catch` або перевірка ініціалізації).
- Контекст ініціалізується лише після першої взаємодії користувача (`click` / `keydown` / `touchstart`) — не при завантаженні.

## 🎥 7. 3D-Сцена та Камера

- **Камера** працює через сферичні координати (`spherical` / `targetSpherical`) з плавною інтерполяцією.
- Підтримуються дві проєкції: **перспективна** (за замовчуванням) та **ортографічна** (`toggleProjection()` / клавіша `O`/`5`).

### 7.1. Ракурс `🧊 Ізометрія` (`setCameraView('iso')`)
- Для ортографічної камери: `Math.atan(Math.SQRT2)` (~54.74°) — справжня аксонометрична ізометрія.
- Для перспективної камери: ~60° — візуальне наближення.
- Обов'язково скидати зміщення панорамування: `targetSpherical.target.set(0, 18, 0)`.
- Обирати найкоротший шлях обертання по колу (нормалізація різниці азимутального кута).

### 7.2. Зняття виділення кнопок ракурсу
- Якщо користувач самостійно крутить сцену мишкою чи тачпадом, клас `.active-cam` повинен автоматично зніматися з кнопок ракурсів у нижньому тулбарі.
- Колбек: `sceneManager.onUserCameraInteraction`.

### 7.3. Доступні Пресети Камери
`'iso'`, `'front'`, `'top'`, `'side'`, `'side90'`, `'bottom'`

## 🖨️ 8. Стандарт Print-Safe (3D-Друк для FDM-принтерів)

- Масштаб: **`1 одиниця Three.js = 1 міліметр`**.
- Геометрія має генеруватися монолітно:
  - Мінімум 1.0 мм суцільної підкладки для піксельних/воксельних моделей.
  - Жодних висячих островів без підтримок (No-Supports).
  - Експорт STL здійснюється безпосередньо у бінарний формат (`Binary STL`), оптимізований для Cura / PrusaSlicer / OrcaSlicer.
- Цільовий принтер: **Anycubic i3 Mega** (стіл 200×200 мм), моделюється в 3D-сцені.
