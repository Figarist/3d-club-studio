# ⚙️ Довідник профілів слайсера для Anycubic i3 Mega («3D Кузня Чудес»)

Цей довідник містить перевірені інженерні налаштування слайсерів (**UltiMaker Cura**, **PrusaSlicer**, **OrcaSlicer**) під принтер **Anycubic i3 Mega** (або сумісні FDM-принтери з кінематикою Cartesian і Bowden-екструдером) для швидкого, надійного та економічного друку дитячих робіт гуртка.

---

## 🎯 1. Апаратні параметри принтера Anycubic i3 Mega

| Вузол принтера | Параметр / Специфікація | Значення для конфігурації слайсера |
|---|---|---|
| **Робоча зона (Bed Size)** | Фізичний розмір Ultrabase: `210 × 210 мм` | **Безпечна зона друку: `200 × 200 мм`, висота `Z: 205 мм`** (з урахуванням кутових затискачів скла) |
| **Форма столу (Bed Shape)** | Прямокутна, нуль координат `(0, 0)` | **Лівий передній кут столу** (Origin: `X=0, Y=0`) |
| **Сопло (Nozzle)** | Латунне стандартне | **Діаметр: `0.4 мм`** |
| **Екструдер** | Bowden (довга тефлонова трубка PTFE) | **Ретракція: `4.5–5.5 мм`** зі швидкістю **`40 мм/с`** |
| **Нитка (Filament)** | PLA 1.75 мм | Робоча температура хотенду: **`200–205 °C`**, столу: **`60 °C`** |
| **Охолодження деталі** | Вентилятор 5015 / 4010 | **0% на 1-му шарі**, **100% починаючи з 3-го шару** |

> [!IMPORTANT]
> **Увага до затискачів скла Anycubic Ultrabase:** металеві кліпси-фіксатори займають по 8–10 мм по краях столу. Веб-студія «3D Кузня Чудес» автоматично попереджає при наближенні габаритів деталі до `190 мм` і блокує експорт при `>200 мм`.

## ⚡ 2. Два базові профілі друку гуртка

Для роботи з 10 учнями в умовах 1 принтера викладачеві потрібні лише **два стандартизовані профілі**. Не потрібно створювати десятки налаштувань — учнівські моделі 25–35 мм ідеально друкуються на одному з них:

### Профіль А: «⚡ Швидкий гуртковий» (Fast Club 0.20 mm)
*Призначений для 85% усіх робіт:* значки, підставки під картон, жетони настільних ігор, таблички для рослин, калібратор пазів.

- **Висота шару (Layer Height):** `0.20 мм`
- **Висота першого шару (First Layer Height):** `0.20 мм` (або `0.24 мм` для компенсації дрібних нерівностей столу)
- **Ширина лінії (Line Width):** `0.40–0.44 мм` (0.44 мм дає міцніше спікання)
- **Товщина стінок (Wall Thickness / Perimeters):** **`3 лінії` (`1.2 мм`)** — *критично для дитячих виробів, щоб вушка брелоків не ламалися!*
- **Суцільні шари (Top/Bottom Layers):** **4 нижні шари** (`0.8 мм`) та **4 верхні шари** (`0.8 мм`)
- **Заповнення (Infill):** `15–20%` (тип: **Gyroid** або **Grid**)
- **Швидкість друку:**
  - Перший шар: **`18–20 мм/с`** (для ідеальної адгезії без клею)
  - Зовнішні стінки: `30 мм/с`
  - Внутрішні стінки: `45 мм/с`
  - Заповнення: `50 мм/с`
  - Холостий хід (Travel): `100 мм/с`
- **Орієнтовний час друку міні-виробу (30×30×6 мм):** **`12–15 хвилин`**, витрата нитки: **`2.5–3.2 грами`**.

---

### Профіль Б: «💎 Детальний рельєфний» (Relief Accent 0.16 mm)
*Призначений для художніх місій:* відбитки скам'янілостей (Місія #6), монети з дрібним рантом (Місія #7), оптичні ілюзії (Місія #12) та крила драконів.

- **Висота шару (Layer Height):** `0.16 мм`
- **Висота першого шару (First Layer Height):** `0.20 мм`
- **Ширина лінії (Line Width):** `0.40 мм`
- **Товщина стінок (Perimeters):** `3 лінії` (`1.2 мм`)
- **Суцільні шари:** **4 нижні** (`0.64 мм`) та **5–6 верхніх** (`0.80–0.96 мм`) — згладжує сходинки
- **Заповнення (Infill):** `20%` (Gyroid або Lines)
- **Швидкість друку:**
  - Перший шар: `18 мм/с`
  - Зовнішні стінки: `25 мм/с` (максимальна чіткість рельєфу)
  - Внутрішні стінки: `40 мм/с`
  - Заповнення: `45 мм/с`
- **Орієнтовний час друку міні-виробу (30×30×6 мм):** **`18–22 хвилини`**, витрата нитки: **`2.8–3.5 грам`**.

## 📏 3. Фізичне калібрування картону та пазів («Правило +0.2 мм»)

У Місії #5 («Картонний мегаполіс») та місіях настільних ігор учні друкують підставки, у які вставляється реальний картон.

### Чому пази вимагають інженерного допуску?
У FDM-друці внутрішні отвори та пази завжди друкуються **вужчими на 0.15–0.25 мм** від математичної 3D-моделі через:
1. Радіальне розширення розплавленого пластику під час витискання соплом (Barus effect).
2. Полігональну апроксимацію кривих і ліній сегментами.
3. Мікронерівності поверхні шарів.

### Стандарти студії «3D Кузня Чудес»:
- Коли учень у студії обирає ширину паза **`2.0 мм`**, студія генерує фізичний проріз **`2.2 мм`** (`номінал + 0.2 мм допуску посадки`).
- Вхід у паз оснащено **45° фаскою (скосом `0.8 мм`)**: картон легко заходить у підставку навіть маленькими пальцями 2–3 класу, не розшаровуючи паперові шари.

### Використання пресету «Калібратор пазів гуртка» (`slot_calibrator`):
- **Габарити калібратора:** `34 × 24 × 8 мм`, маса: ~2.3 грами PLA.
- **Час друку:** всього **`12–14 хвилин`** на профілі `Fast Club 0.20 mm`.
- **4 калібровані пази з рельєфним маркуванням:**
  - `1.5 мм` (фактичний зазор `1.7 мм`) — для тонкого палітурного або щільного коробкового картону (листівки, пакувальні коробки чаю/печива).
  - `2.0 мм` (фактичний зазор `2.2 мм`) — **стандартний палітурний картон для уроків праці/моделювання**.
  - `2.5 мм` (фактичний зазор `2.7 мм`) — мікро-гофрокартон (профіль E, 3-шаровий тонкий).
  - `3.0 мм` (фактичний зазор `3.2 мм`) — стандартний поштовий 3-шаровий гофрокартон (профіль B/C).
- **Порядок дій викладача перед уроком:**
  1. Надрукувати один зразок калібратора перед стартом теми.
  2. Взяти зразок наявного картону, який принесли діти, та вставити у 4 пази.
  3. Знайти паз із щільною, але легкою посадкою («ковзає без заминання й тримає вертикаль під кутом 90°»).
  4. Оголосити учням: *«Сьогодні для наших підставок обираємо паз `2.0 мм`!»*

## 🛠️ 4. Покрокове налаштування у популярних слайсерах

### 1. UltiMaker Cura (v5.x)
1. **Додавання принтера:** `Settings` → `Printer` → `Add Printer` → `Non-UltiMaker` → `Anycubic` → **`Anycubic i3 Mega`**.
2. **Quality:** `Layer Height = 0.2 mm` (або `0.16 mm`), `Initial Layer Height = 0.2 mm`.
3. **Walls:** `Wall Line Count = 3` (або `Wall Thickness = 1.2 mm`).
4. **Top/Bottom:** `Top Layers = 4`, `Bottom Layers = 4`.
5. **Infill:** `Infill Density = 15%`, `Infill Pattern = Gyroid`.
6. **Material:** `Printing Temperature = 205 °C`, `Build Plate Temperature = 60 °C`.
7. **Speed:** `Print Speed = 45 mm/s`, `Outer Wall Speed = 30 mm/s`, `Initial Layer Speed = 18 mm/s`.
8. **Travel (Retraction):**
   - `Enable Retraction = Checked`
   - `Retraction Distance = 5.0 mm`
   - `Retraction Speed = 40 mm/s`
   - `Retract at Layer Change = Checked`
   - `Combing Mode = Within Infill` (запобігає появі рубців на лицьовій стороні рельєфу).
9. **Build Plate Adhesion:**
   - Для моделей «3D Кузні» із суцільною підкладкою використовуйте **`Skirt`** (2 лінії на відстані 4 мм від деталі). Рафт чи брім не потрібні, оскільки моделі мають плоску основу `Z=0`!

---

### 2. PrusaSlicer (v2.7+)
1. **Конфігурація принтера:** `Configuration` → `Configuration Wizard` → `Other Vendors` → `Anycubic` → **`Anycubic i3 Mega (0.4 nozzle)`**.
2. **Print Settings:**
   - `Layer height: 0.2 mm`
   - `First layer height: 0.2 mm`
   - `Perimeters: 3`
   - `Solid layers: Top 4, Bottom 4`
   - `Fill density: 15%`, `Fill pattern: Gyroid`
3. **Speed:**
   - `Perimeters: 40 mm/s`, `Small perimeters: 25 mm/s`, `External perimeters: 30 mm/s`
   - `First layer speed: 18 mm/s` (або `40%`)
4. **Filament Settings:**
   - `Extrusion multiplier: 1.0`
   - `Temperature: Nozzle 205 °C, Bed 60 °C`
5. **Printer Settings (Extruder 1):**
   - `Retraction Length: 5.0 mm`
   - `Retraction Speed: 40 mm/s`
   - `Wipe while retracting: Checked`

---

### 3. OrcaSlicer (v2.x)
1. Виберіть профіль принтера **`Anycubic Mega i3 0.4 nozzle`**.
2. **Quality:** `Layer height = 0.20 mm`, `First layer = 0.20 mm`.
3. **Strength:** `Wall loops = 3`, `Top shell layers = 4`, `Bottom shell layers = 4`.
4. **Infill:** `Sparse infill density = 15%`, `Sparse infill pattern = Gyroid`.
5. **Speed:** `First layer = 20 mm/s`, `Outer wall = 35 mm/s`, `Inner wall = 45 mm/s`.
6. **Extruder:** `Retraction length = 5.0 mm`, `Retraction speed = 40 mm/s`.

## 🏷️ 5. Правила черги друку та експорту G-Code

Щоб викладач або черговий учень не плуталися у десятках однотипних файлів на SD-картці принтера:

### 1. Формула назви файлу для SD-карти:
```text
P<НомерПари>_M<НомерМісії>_<Назва>_V<1чи2>_<ЧасУХвилинах>m.gcode
```
**Приклади:**
- `P01_M05_cardstand_V2_14m.gcode` — Пара №1, Місія #5 (Підставка для картону), Версія 2 (фінальна), час 14 хв.
- `P03_M01_shield_V2_16m.gcode` — Пара №3, Місія #1 (Щит лицаря), 16 хв.
- `PRESET_slot_calibrator_13m.gcode` — Тестовий калібратор пазів гуртка, 13 хв.

### 2. Пакетний друк між заняттями (Plate Batching):
- Якщо викладач запускає декілька дитячих міні-моделей одночасно після уроків:
  - Розташовуйте деталі на столі з **дистанцією не менше 15–20 мм** між ними.
  - Розміщуйте від центру столу до країв.
  - Уникайте друку впритул до кліпс Ultrabase.
  - Режим друку: **All at once** (одночасно) — зменшує ризик зачеплення суміжних деталей головкою хотенду.

## 🧽 6. Догляд за столом Anycubic Ultrabase для безвідмовної адгезії

Поверхня Ultrabase має мікропористе керамічне покриття. При температурі 60 °C пори розширюються і надійно утримують PLA, а при охолодженні нижче 35 °C — деталь буквально сама відскакує зі столу.

1. **Знежирення перед запуском черги:** протерти стіл серветкою з **ізопропіловим спиртом (IPA)** або промити теплою водою з милом (раз на місяць).
2. **Ніколи не шкребти гарячий стіл металевим шпателем:** це здирає мікропористе покриття Ultrabase. Дочекайтеся охолодження до 30 °C — деталь зніметься легким дотиком руки.
3. **Калібрування по 4 кутах аркушем чека/паперу 80 г/м²:** сопло повинно з легким приємним тертям затискати аркуш паперу у всіх 4 кутах над регулювальними гвинтами.
4. **Перевірка першого шару:** лінії спідниці (`skirt`) повинні бути злегка приплюснутими, без розривів і без «хвиль» від надто сильного вдавлювання сопла.
