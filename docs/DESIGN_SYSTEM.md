# 🎨 Дизайн-система «Friendly Arcade» (LEGO & 3D Club Ecosystem)

> **Статус:** Офіційний спільний стандарт стилю для освітніх веб-застосунків **LEGO WeDo 2.0 Catalog** та **3D Club Studio**.  
> **Стек:** Pure Vanilla CSS, 100% офлайн, нуль зовнішніх бібліотек, шрифтів та CDN.

---

## 1. Концепція та Філософія

«Friendly Arcade» — це ігровий, доброзичливий та висококонтрастний візуальний дрескод, створений спеціально для дітей 6–12 років (2–6 класи), вчителів робототехніки та STEM-гуртків.

- **Ігрова естетика (Roblox / Nintendo / Arcade):** великі м'які радіуси заокруглення (16–24px), товсті інженерні рамки (2–3px), пігулкоподібні кнопки (pill buttons), виразні тактильні мікро-взаємодії (`hover` підйом, `active` стискання).
- **Магічна нічна палітра:** глибокий космічний індиго/ультрамарин (`#1a1a2e` / `#0f3460`) замість брудного чорного або нудного сірого.
- **LEGO-акценти:** живі чисті кольори кубиків LEGO (зелений, електрик-синій, сонячний жовтий, полум'яний помаранчевий, пурпуровий, кораловий червоний).
- **Доступність (WCAG AA) та безвідмовність:**
  - Суворий контраст тексту над фоном (не менше 4.5:1 для тексту, 3:1 для інтерфейсних рамок).
  - Спеціальний темний колір `--on-green: #06210f` для читабельності поверх яскраво-зеленого CTA.
  - Повна підтримка `:focus-visible` (яскравий блакитний контур 3px) для навігації клавіатурою.
  - Повага до `prefers-reduced-motion` для дітей з чутливістю до руху.
  - Сенсорні мішені не менше 44×44px на мобільних пристроях і планшетах.

## 3. Стандарти Компонентів

### Кнопки (`.btn`)
- **Форма:** Радіус `--r-pill` (або `--r-md`), рамка 2px (`solid var(--surface2)`), жирний текст (`font-weight: 800`).
- **Модифікатор `--primary` (зелена):** `background: var(--green); color: var(--on-green); border-color: transparent;`. При наведенні: `background: var(--green-dark); box-shadow: var(--shadow-glow-green); transform: translateY(-2px);`. При натисканні: `transform: scale(0.96);`.
- **Модифікатор `--accent` (жовта):** `background: var(--yellow); color: var(--on-yellow);`.
- **Модифікатор `--ghost`:** прозоре тло, рамка `--surface2`, колір `--text`.

### Пігулки та Лічильники (`.pill`)
- Використовуються для перемикачів мови, статусів, кількості зібраного чи перевірок.
- `border-radius: var(--r-pill); padding: 4px 12px; font-weight: 800;`.

### Картки (`.card`, `.panel-card`)
- `border-radius: var(--r-md); border: 3px solid transparent; background: var(--card);`.
- У каталогах та списках при ховері: `transform: translateY(-8px) scale(1.02); border-color: var(--green); box-shadow: 0 12px 40px rgba(0, 210, 106, 0.2);`.
- **Примітка для CAD-панелей:** стаціонарні робочі панелі інструментів не «підстрибують» на ховері, щоб не збивати приціл курсора учня.

### Модальні вікна (`.modal-window`)
- Заокруглення `--r-lg` (24px).
- Рамка 3px `var(--surface2)`.
- Тло: `var(--bg)` або `var(--surface)` з м'яким затемненням `rgba(0, 0, 0, 0.75)`.
- Обов'язкова кнопка закриття ✕ праворуч зверху (розмір не менше 36×36px, радіус `--r-pill` або `--r-md`).
- Обмеження висоти `max-height: 90vh` із внутрішнім скролом.

### Доступність та Фокус
```css
:focus-visible {
  outline: 3px solid var(--cyan) !important;
  outline-offset: 2px !important;
}

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

## 4. Правила чистоти та заборони
1. ❌ **Жодного CDN та зовнішніх шрифтів:** жодних `fonts.googleapis.com`, `cdnjs`, FontAwesome тощо. Все працює 100% офлайн у літаку/укритті без мережі.
2. ❌ **Жодних inline-стилів для візуальних ефектів:** стилі описуються виключно в CSS-класах.
3. ❌ **Жодного нечитабельного тексту:** білий текст на світло-зеленому чи жовтому тлі суворо заборонений (використовувати `--on-green` та `--on-yellow`).
4. ❌ **Жодної зміни логіки 3D-сцени:** у 3D Club Studio стиль стосується лише UI-обв'язки (панелі, кнопки, модалки, картки), а не освітлення моделі та STL-експортера.

## 5. Першоджерело (Upstream) та Історія Міграції (v2.0.0)

* **Офіційний відкритий репозиторій дизайн-системи:** [github.com/Figarist/friendly-arcade](https://github.com/Figarist/friendly-arcade)
* **Жива вітрина та документація:** [figarist.github.io/friendly-arcade](https://figarist.github.io/friendly-arcade/)

### Що було змінено у 3D Club Studio (Реліз v2.0.0 Friendly Arcade Edition):
1. **Міграція палітри:** Повний перехід від похмурого сланцю Slate/Obsidian (`#080d16`, `#0b1120`, `#0f172a`, `#1e293b`) на доброзичливий нічний аркадний спектр (`#1a1a2e`, `#16213e`, `#0f3460`, `--card: #1e3a5f`).
2. **Карта сумісності (Aliases):** Збережено псевдоніми старих змінних (`--bg-canvas`, `--bg-surface`, `--accent-craft`), що виключає зламані стилі у 3100+ рядках коду студії.
3. **Уніфікація карток:** Каталог 72 місій (`.mission-card`) отримав стиль Roblox-tile з анімацією ховеру `translateY(-8px) scale(1.02)` та зеленою рамкою.
4. **Стандартизація модалок:** Радіус заокруглення піднято до `--r-lg: 24px`, кнопку закриття ✕ переведено у круглу форму 36×36px з м'яким червоним ховером.
5. **Оновлення розширень:** Скоординовано суміжні таблиці стилів `adventure-shelf.css`, `pixel-editor-tools.css`, `lesson-companion.css`.
6. **Синхронізація версії:** Версія 2.0.0 зафіксована у 4 обов'язкових точках (`index.html`, `src/app.js`, `src/passportPrintController.js`, `README.md`).
7. **Колір браузера:** Тег `<meta name="theme-color">` синхронізовано на `#1a1a2e`.
8. **Промо-інтеграція:** У модальне вікно «Про автора» додано перехід на відкритий репозиторій `friendly-arcade`.
