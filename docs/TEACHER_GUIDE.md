# 📘 Методичний посібник для викладача гуртка 3D-моделювання (2–6 класи)

Цей документ містить практичні сценарії проведення занять із використанням веб-студії **«3D Кузня Чудес»** у поєднанні з **Tinkercad**, **Makers Empire** та шкільним 3D-принтером.

---

## 🎓 5 Готових Сценаріїв Занять («ВАУ-Уроки»)

### Урок 1: «Мій Перший Іменний Артефакт із Minecraft» (2–4 класи)
- **Мета:** Познайомити дітей із поняттям висоти шару (`Z-axis`) та пошарової побудови 3D-моделі.
- **Хід уроку:**
  1. Відкрийте вкладку **«⛏️ Майнкрафт-Кузня»** на проекторі/головному екрані.
  2. Покажіть, як плоский малюнок `16×16` перетворюється на різнорівневий рельєф (де `Шар 1` — найнижчий, а `Шар 4` — найвищий).
  3. Запросіть кожного учня підійти (або продиктувати з місця) зміни до власного меча/кірки/тотема та вписати своє ім'я в поле *«Ім'я учня»*.
  4. Натисніть **«🔥 Симуляція 3D-Принтера»**, щоб діти побачили, як сопло принтера друкуватиме спочатку основу `2 мм`, а потім вищі деталі й літери імені.
  5. Експортуйте `.STL` та запустіть груповий друк брелоків.

### Урок 2: «Лицарський Щит або Бос-Заготовка для Tinkercad» (3–6 класи)
- **Мета:** Навчити дітей імпортувати готову складну 3D-базу у **Tinkercad / Makers Empire** і модифікувати її (булеві операції додавання та вирізання).
- **Хід уроку:**
  1. У вкладці **«⛏️ Майнкрафт-Кузня»** оберіть шаблон **`🛡️ Щит (Tinkercad)`** (або у вкладці **«👾 Мутатор Мобів»** увімкніть галочку **«🧩 Режим Заготовки для Tinkercad»**).
  2. Завантажте `.STL` файл заготовки та роздайте його учням на їхні комп'ютери.
  3. У **Tinkercad** учні натискають `Import` -> завантажують щит або корпус моба.
  4. **Завдання для учнів:**
     - Додати на щит власний 3D-герб, ініціали або наскрізні візерунки (через `Hole`).
     - Змоделювати зі зворотного боку щита ручку або кріплення для фігурки.
     - Для заготовки моба — самостійно зробити очі, рот, шолом чи нагрудний реактор.

### Урок 3: «Секретна Оптична Ілюзія 0° / 90°» (4–6 класи)
- **Мета:** Розвиток просторової уяви та вивчення 3D-проекцій (вигляд спереду `X-Y` та вигляд збоку `Z-Y`).
- **Хід уроку:**
  1. Відкрийте вкладку **«🔮 Оптичний Перевертень»**.
  2. Запитайте учнів: *«Чи можливо зробити одну суцільну деталь без жодного рухомого елемента, яка спереду показує ваше ім'я, а збоку — слово BOSS або меч і кріпера?»*
  3. Введіть ім'я учня у `Слово 1` та друге слово/іконки у `Слово 2`.
  4. Натискайте по черзі великі сині кнопки внизу екрана: **«👁️ Показати СЛОВО 1 (0°)»** та **«🔄 Повернути на СЛОВО 2 (90°)»**.
  5. Поясніть учням принцип перетину двох екструзій (булева операція `Intersection`), який вони також можуть спробувати повторити на одній літері в Tinkercad.

### Урок 4: «Інженерна Битва: Монолітна Пружинна Катапульта» (3–6 класи)
- **Мета:** Познайомити дітей із пружними деформаціями пластику (*Compliant Mechanisms*) — як змусити твердий пластик працювати як пружина без жодної металевої деталі чи шестерні.
- **Хід уроку:**
  1. Відкрийте вкладку **«🎯 Катапульта і Баланс»** -> режим **«🏹 Монолітна Пружинна Міні-Катапульта + TNT»**.
  2. Натисніть **«🚀 ВИСТРІЛИТИ З КАТАПУЛЬТИ!»**, щоб продемонструвати згин C-подібної ресори та політ снаряда.
  3. Покажіть дітям, чому ми змінюємо повзунок *«Товщина пластикової ресори»* (`1.8 мм` — м'яка пружина для легких паперових кульок, `2.8 мм` — потужна туга пружина).
  4. Надрукуйте 2 катапульти з різною товщиною ресори (вони друкуються пласко всього по ~20 хвилин) і влаштуйте в кінці уроку змагання зі стрільби по паперових вежах!

### Урок 5: «Загадка Центру Мас: Дракон, що стоїть на кінчику носа» (2–6 класи)
- **Мета:** Наочно показати фізику рівноваги тіл та поняття центру тяжіння.
- **Хід уроку:**
  1. У вкладці **«🎯 Катапульта і Баланс»** перемкніть список на **«🦅 Гравітаційний Балансир „Дракон на Пальці“»**.
  2. Натисніть **«👆 Протестувати Магічний Баланс!»**.
  3. Зверніть увагу дітей на те, чому крила дракона сильно винесені вперед за лінію його носа і мають потовщення на кінцях — саме ці баластні куби перетягують центр мас точно під точку опори.

## 🛠️ Практичні Поради для Старого / Простого 3D-Принтера

Усі моделі зі студії «3D Кузня Чудес» спроектовані так, щоб пробачати похибки старих шкільних принтерів (люфти ременів, нерівний стіл, відсутність обдуву чи старе сопло):

1. **Налаштування в Слайсері (Cura / PrusaSlicer / OrcaSlicer):**
   - **Підтримки (Supports):** `OFF` (Вимкнено! Жодна модель зі студії не потребує підтримок).
   - **Висота шару (Layer Height):** `0.20 мм` або `0.25 мм` (або `0.28 мм` для швидкого друку під час уроку).
   - **Кількість стінок / периметрів (Wall Line Count / Perimeters):**
     - Для брелоків, ілюзій та мобів: `2–3 стінки`, заповнення (`Infill`) `15–20%`.
     - Для **Пружинної Катапульти**: рекомендується `3–4 стінки` (`Perimeters = 4`), щоб C-подібна ресора складалася зі суцільних поздовжніх ниток пластику — тоді вона витримує тисячі пострілів і ніколи не ламається!
   - **Прилипання до столу (Build Plate Adhesion):** `Skirt` (або `Brim 4 мм`, якщо стіл старий і кути деталей іноді відклеюються).

2. **Лайфхак: Двоколірний друк на найстарішому одноколірному принтері!**
   - Оскільки в модулі **«⛏️ Майнкрафт-Кузня»** кожен колір має власну висоту в міліметрах (наприклад, підкладка `0–2 мм`, основне тіло `2–4.5 мм`, алмазний рельєф та ім'я `4.5–7.5 мм`), ви можете під час друку на висоті `2.2 мм` або `4.6 мм` натиснути на принтері **`Pause -> Change Filament`** і вставити пластик іншого кольору!
   - Дитина отримає справжній дво- або триколірний Майнкрафт-брелок навіть на найпростішому принтері з одним екструдером.
