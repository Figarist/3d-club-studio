# Пригодницький пак

Початковий Adventure Pack додає 12 місій українською та 12 пов’язаних рельєфних пресетів для Minecraft-Кузні. Його теми — космічна експедиція, природні детективи та міські майстри. У релізі 1.9.0 каталог містить 72 місії загалом; окремо від цього паку додано 48 моделей: 20 рельєфів і корисних предметів, 12 персонажів та істот, 8 оптичних відкриттів і 8 моделей ігрової інженерії.

## Сталі ключі й реєстрація

Ключі цього паку та його ідентичності залишаються незмінними. Його місії мають ID 13–24, стабільні ключі виду `studio-adventure-pack:<presetKey>`, а ключі пресетів і далі починаються з `adv_`.

Пак реєструється атомарно через `StudioContentRegistry.registerPack`: повний набір перевіряється перед додаванням пресетів і місій. `window.StudioAdventurePack` надає метадані, перелік ключів пресетів, ID місій, відповідність ключів ID та три тематичні групи. Інші контент-паки використовують власні ідентичності; не перейменовуйте ці старі ключі, коли оновлюєте каталог або його UI.

У `index.html` джерело істини для порядку завантаження. Потрібні залежності мають залишатися до `app.js`: `contentRegistry.js` → `missionManager.js` → `projectState.js` та `modalFocus.js` → контролери → генератори → `content/adventurePack.js` → `content/funReliefs.js`, `content/funDiscoveries.js`, `content/funEngineering.js` → `adventureShelf.js` → інші UI-модулі → `sceneManager.js` → `app.js`.

## Навчальна робота з місіями

Картки використовують наявні фільтри `relief`, `texture`, `boardgame`, `useful`, `cardboard` та `optical`. Вони містять підказку для старту, варіанти завдання для 2–3 і 4–6 класів, послідовність кроків і короткий чекліст. Пресет — початкова цифрова заготовка: учитель може запропонувати дитині змінити клітинки або іншу названу рису й пояснити рішення.

Усі пресети цього паку — повні сітки 16×16 із рівнями 0–4. У рекомендованій конфігурації розмір клітинки 1.8 мм дає сітці номінальну ширину 28.8 мм; крок висоти 0.9 мм і суцільна основа 2.0 мм задають розмір лише для цієї конфігурації. Тип кріплення — `none`. Це параметри згенерованого задуму, а не виміри надрукованої деталі.

Реєстраційна перевірка пресету контролює розмір сітки, діапазон рівнів, наявність рівнів 1–4 та зв’язність активних клітинок по сторонам. Вона не доводить замкненість чи manifold-властивості 3D-поверхні, коректне нарізання, придатність до друку, посадку або міцність.

Нові 48 місій каталогу стартують у режимі одного пластику. Під час роботи зі збереженими проєктами зберігайте дитячу сітку й монохромне налаштування, записане в проєкті; не замінюйте їх значеннями за замовчуванням під час оновлення UI. Три опційні поля дизайну, відсутні в старому імпорті, використовують передбачені програмою класичні значення.

## Межі підтверджених результатів

Місії паку завершуються цифровим переглядом, збереженням проєкту та поясненням задуму. Якщо вчитель планує друк, слід окремо пройти [перевірку у слайсері](SLICER_PROFILES.md). Екранний запуск, тінь або зміна ракурсу є поведінкою демонстрації у програмі; вони не встановлюють фізичну силу чи результат друку.

В [огляді контенту](FUN_CONTENT_REVIEW.md) для релізу 1.9.0 зафіксовано 101 скінченну конфігурацію, 4/101 завершені фінальні захоплення з основним переглядом, 13 оригінальних знімків і 97 конфігурацій, що очікують. Це не є повним прийманням каталогу. Додаткові обмеження екранних демонстрацій, фізичних механізмів і друку наведені в [посібнику викладача](TEACHER_GUIDE.md); фізичні результати залишаються **Not verified**.
