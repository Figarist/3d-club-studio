## 🏗️ ФАЗА 1: КЛІНАП «БЕКЕНДУ» ТА АРХІТЕКТУРИ РУШІЯ

1. **Рефакторинг монолітного `src/app.js` (~2400 рядків):**
   - Розбий логіку всередині `src/app.js` (або виділи допоміжні модулі без порушення роботи через локальний запуск `file://index.html`):
     - `MissionManager` (вибір, стан чек-листів, фільтри місій).
     - `HistoryManager` (Undo / Redo, ліміти, серіалізація).
     - `SnapshotCompareController` (V1 capture, порівняння, розрахунок дельти метрик).
     - `PassportPrintController` (генерація Canvas 2D паспорта, буфер обміну, друк).
   - Усунь дублювання оголошень змінних, застарілі обробники подій та мертві функції.
   - Очисти кеш DOM: переконайся, що кожен елемент має єдину точку правди та відсутні звернення до `null`/`undefined`.

2. **Аудит пам'яті Three.js та геометрій (`src/sceneManager.js`, `src/generators/*`):**
   - Перевір коректне рекурсивне звільнення пам'яті (`geometry.dispose()`, `material.dispose()`, `texture.dispose()`).
   - Переконайся, що жодна тимчасова сітка, контур чи ефект не створює memory leak при частому малюванні на полотні 16×16.
   - Перевір математику центрування та BoundingBox: модель завжди повинна ідеально торкатися дном площини $Z=0$ без провалювання під стіл чи ширяння у повітрі.

3. **Стійкість та серіалізація стану:**
   - Валідація структури `localStorage` та імпортованих файлів `.json`: схема повинна мати чіткі дефолтні значення і ніколи не викликати падіння студії при пошкодженому або застарілому файлі.
   - Забезпеч безвідмовну роботу в приватному режимі браузера (коли `localStorage` кидає `SecurityError` або квота заблокована).

2. **Піксель-редактор 16×16 (Майнкрафт-Кузня):**
   - Зроби сітку візуально смачною: приємні заокруглення кутів, акуратні мікро-проміжки між вокселями, тактильна підсвітка клітинки під курсором.

   - Додай дзеркальну розмітку (тонкі пунктирні напрямні по центру осі X та Y для полегшення малювання симетрії).

3. **3D-Сцена та плаваючий HUD (Viewport Overhaul):**
   - **Стіл 3D-принтера:** перетвори сітку столу на естетичний матовий стіл Anycubic Ultrabase з гравіюванням центру, безпечної зони друку та міліметровими мітками.
   - **Інфо-бейдж розмірів:** стильний напівпрозорий скляний віджет (Glassmorphism / Frosted Slate) у кутку сцени. Моноширинні цифри розмірів, статус столу, розрахунок грамів PLA та індикатор плоского дна $Z=0$.
   - **Швидкий вигляд камери:** мінімалістичні кнопки (`👁️ 0°`, `🔄 90°`, `🔝 Зверху`, `🧊 Ізометрія`) з плавними кінематографічними переходами камери Three.js.

4. **Модальні вікна (Порівняння V1 ↔ V2 та Паспорт деталі):**
   - **Модалка V1 ↔ V2:**
     - Вигляд має нагадувати сучасний аналітичний екран: два чистих бокси V1 та V2 з контрастними бейджами (Фіолетовий бурштин проти Смарагду).
     - Показ дельти: червоні/зелені бейджі різниці (наприклад, `Острови: 3 🚨 → 1 ✅`, `Час: 18 хв → 13 хв (-28%)`).
     - Блок рефлексії учня з естетичним оформленням питань для уроку.
   - **Паспорт для черги друку:**
     - У браузері та на папері повинен виглядати як бездоганний інженерний технічний документ (чисті лінії, якісна типографіка, поле для рукописного підпису викладача).
     - Завантаження PNG повинно рендерити картку ультрависокої якості (HiDPI/Retina 2x) без мильних літер.

5. **Мікро-взаємодії та звукова синергія:**
   - Тривалість анімацій hover/active: `120–160ms` із кривою `cubic-bezier(0.16, 1, 0.3, 1)`.
   - Запобігай будь-якому випадковому Layout Shift (зсуву сусідніх елементів при ховері або появі помилок).
   - Збалансуй гучність Web Audio синтезатора: звуки кліків, малювання та генерації повинні звучати тепло, м'яко, приємно на слух (не різати вуха дітям у навушниках).
